# soccer_manager

サッカークラブ経営・育成シミュレーションのスマホアプリ（Flutter + Flame）。

自分のクラブを創設し、下記のループを繰り返してリーグ優勝を目指す。

- **トレーニング**: 攻撃・守備・体力強化・休養の中から週ごとの方針を選び、選手を育成する
- **試合**: リーグ日程を1節ずつ消化。簡易シミュレーションエンジンが試合展開・得点者を算出する
- **日程・順位表**: 全チームの成績・順位を確認する
- **スカッド**: 保有選手の能力（攻撃・守備・技術・スタミナ・潜在能力・疲労・士気）を確認する

進行状況は端末内（`shared_preferences`）に自動保存される。

## 構成

```
lib/
  models/     Player・Team・League・Fixture・MatchResult・SaveGame（すべてJSONシリアライズ可能）
  logic/      選手生成・試合シミュレーション・トレーニング・リーグ日程生成のロジック
  state/      GameState（ChangeNotifier） - セーブ/ロードとゲーム進行を管理
  game/       Flame製の簡易ピッチアニメーション（試合結果画面で再生）
  screens/    各画面のUI
  widgets/    共通ウィジェット
  data/       選手名・クラブ名のダミー名称プール
```

## 既知の制約（v1時点）

- リーグは自クラブ+CPU7クラブの計8チーム、ホーム&アウェイ総当たり（14節/シーズン）。
- 移籍・資金・スタジアム経営などは未実装。育成とリーグ戦の基本ループのみ。
- 選手名・クラブ名は架空のダミー名称プールからランダム生成しており、実在の選手・チームとは無関係。
- iOS/Androidの実機ビルド設定（署名・ストア申請等）は未対応。
