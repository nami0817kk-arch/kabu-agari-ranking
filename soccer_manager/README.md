# soccer_manager

サッカークラブ経営・育成シミュレーションのスマホアプリ（Flutter + Flame）。

Web版（お試し公開）: https://nami0817kk-arch.github.io/kabu-agari-ranking/play/
（`.github/workflows/soccer-manager-web.yml` がpush時にビルド・GitHub Pagesへ自動デプロイする。
既存の値上がりランキングサイトのデプロイ先(Cloudflare Pages)とは独立しており影響しない）

自分のクラブを創設し、下記のループを繰り返してリーグ優勝を目指す。

- **トレーニング**: 攻撃・守備・体力強化・休養の中から週ごとの方針を選び、選手を育成する
- **スタメン編成**: フォーメーション（4-4-2/4-3-3/3-5-2/5-3-2）を選び、ポジション別の人数枠に沿ってスタメン11人を編成する。フォーメーションは試合の攻撃力・守備力にも影響する
- **移籍市場**: 資金の範囲内で選手を獲得したり、保有選手を放出して資金を得たりできる
- **試合**: リーグ日程を1節ずつ消化。スタメン・フォーメーションを反映した簡易シミュレーションエンジンが試合展開・得点者を算出し、出場した選手には負傷が発生することもある
- **理事会**: シーズンごとに目標順位が示され、勝敗や順位次第で監督への信頼度が増減する。信頼度が0になると解任され、新しいクラブでの再出発となる
- **日程・順位表**: 全チームの成績・順位を確認する
- **スカッド**: 保有選手の能力（攻撃・守備・技術・スタミナ・潜在能力・疲労・士気・負傷状況・市場価値）を確認する

進行状況は端末内（`shared_preferences`）に自動保存される。

## 構成

```
lib/
  models/     Player・Team・League・Fixture・MatchResult・SaveGame（すべてJSONシリアライズ可能）
  logic/      選手生成・試合シミュレーション・トレーニング・リーグ日程生成のロジック
  state/      GameState（ChangeNotifier） - セーブ/ロードとゲーム進行を管理
  game/       Flame製の簡易ピッチアニメーション（試合結果画面で再生）
  screens/    各画面のUI
  widgets/    共通ウィジェット
  data/       選手名・クラブ名のダミー名称プール
```

## 既知の制約（v1時点）

- リーグは自クラブ+CPU7クラブの計8チーム、ホーム&アウェイ総当たり（14節/シーズン）。
- CPUクラブは資金・移籍・フォーメーション変更を行わない（初期スタメンのまま固定）。
- スタジアム経営・スタッフ・記者会見などは未実装。
- 選手名・クラブ名は架空のダミー名称プールからランダム生成しており、実在の選手・チームとは無関係。
- iOS/Androidの実機ビルド設定（署名・ストア申請等）は未対応。
